## 模型实验

本地三题分别执行 600、600、1000 个控制步，仿真与策略执行耗时约 166、158、283 秒。网站三题自测共 114 次模型调用，处理耗时 11 分 31 秒，三个场景均无非法动作。网页视频为 512×256、20fps，三段长度约 30、30、50 秒，按仿真时间播放。

同一 ZIP 的五题终评执行 5400 个控制步，258 次模型调用，处理耗时 24 分 55 秒，五题均无非法动作，得分 0/100。终评记录 `e1ea0e1c-0df1-49d7-a7ca-e4cd49234718` 与开发记录 `70f0445d-df87-4267-b4c9-4b9ba6e52e26` 保留相同作品校验值。

本轮视觉模型的公开题得分为 0/50，轨迹中仍有定位误差、抓取判断错误和重复动作。该记录用于验证学生从修改到分析的真实流程。此前物理校准与固定动作复现实验另用于核对目标判定、有效达成步数和计分，其成绩不作为视觉模型表现。

开启 thinking 的早期实验出现单次输出被推理内容占满的情况，失败记录保留。最终验收作品使用 `thinking=false`、单次输出 4096、请求等待 135 秒；模型名与网站 API 平台一致。

## 运行与发布

开发自测使用 1800 秒、300 次模型调用，五题终评使用 7200 秒、500 次调用，控制步数上限依次为 600、600、1000、1600、1600。终评通过专用内部网络访问模型代理；选手容器无法直连外网或宿主机 SSH，私有场景和评测结果目录未挂载给选手。

真实学生账号在发布前请求最终运行返回 403，访问全部 15 个终评文件返回 404；作品页状态为等待发布，开发记录仍可读取。代码通过/不通过审阅已在网页保存。

发布后重新登录学生账号，作品页展示五题结果及原三题开发记录；五段终评视频均载入成功，最后一段实际播放。第五题轨迹下载返回 200 和附件响应头，包含 1600 个控制步。

生产接入命令、配置生成、镜像导入与终评发布流程见 [五题版本接入](libero-v2-activation.md)。公开开发包及 Docker 环境已发布；组织方镜像与私有场景通过独立交付包提供。
