# A 观行知意｜CV · 深度学习 · 动作识别

使用 CUHK-X 数据集中的深度图像与红外图像，识别 40 类日常动作。参赛队伍完成数据处理、分类模型训练和效果验证，可研究时序采样、人物裁剪、模态融合、模型结构与数据增强。

建议学习 Python、PyTorch、图像与视频处理、模型微调和评估。每队提供 100 元 AutoDL 算力券。

## 数据

训练集包含 1,995 段动作片段，公开验证集包含 466 段。每段提供同步的伪彩深度图 `Depth_Color` 和红外图 `IR`，最多 32 帧，分辨率为 304×228。深度图保留 RGB 伪彩编码，IR 为 8 位灰度图。类别映射、人物划分和样本 ID 沿用本届原版本。

数据按训练集、验证集分别提供 ZIP 分卷。`dataset-index.json` 列出文件大小、SHA256 和集合信息；开发包内的数据安装器支持下载、校验和安装。每个集合的 `manifest.json` 提供样本目录、标签和片段校验值，`provenance.json` 记录来源和采样方式。

## 模型与训练

允许使用公开预训练权重和微调，建议从配套 baseline 开始。技术说明中列明预训练模型、权重来源、训练数据与微调设置。分类器、检测器及其他参与推理的模型，参数总量不超过 100M。

队伍可以调整取帧数量与位置、人物裁剪、输入尺寸和深度／IR 融合方式。模型选择与参数调整使用训练集和公开验证集；组织方最终测试集按统一规格独立评测。

## 提交材料

1. 训练与推理代码、运行配置和依赖说明。
2. 模型权重及 SHA256。较大权重通过固定 HTTPS 地址提供，推理 ZIP 中填写权重地址、大小与校验值。
3. 公开验证集预测结果，包含样本 ID 和预测类别。
4. 技术说明：数据处理、模型设计、训练设置、验证结果、实验分析和复现命令。

推理接口为 `Model(config, device).predict(sample_path)`，返回按固定类别顺序排列的 40 个有限分数。`sample_path` 指向当前片段目录，内含同步的 `Depth_Color/` 与 `IR/` 图像。预处理、人物检测和分类过程包含在队伍的推理代码中。

## 项目成果评分

准确率 `A`、40 类 Macro F1 `F` 均使用百分制。平均推理延迟 `L` 使用毫秒，效率系数为 `E=min(1,100/max(L,0.001))`。

**项目成果分 = 0.80×A + 0.10×F + 0.10×A×E，满分 100 分。**

计时包含图像读取、预处理、人物检测、分类预测与 CUDA 同步。首样本计入准确率并用于计时预热。评测硬件、环境、数据版本和时间限制统一公布。

技术说明与答辩可介绍方法比较、消融实验、错例分析和研究发现。
