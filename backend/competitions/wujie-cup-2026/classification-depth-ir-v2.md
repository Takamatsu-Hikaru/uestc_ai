# 观行知意：人体日常行为识别挑战赛

使用 CUHK-X 数据集中的深度图像与红外图像，识别 **40 类日常动作**。参赛队伍以公开预训练模型微调为起点，完成数据处理、模型训练、效果验证和推理程序，可研究时序采样、人物裁剪、模态融合、模型结构与数据增强。

建议学习 Python、PyTorch、图像与视频处理、模型微调和评估。每队提供 **100 元 AutoDL 算力券**。

## 数据

| 数据 | 数量 | 用途 |
|---|---:|---|
| 训练集 | **1,995 段** | 模型训练与微调 |
| 公开验证集 | **466 段** | 方法比较、参数选择与错例分析 |
| 组织方测试集 | **470 段** | 平台测评，数据与标签保存在独立评测环境 |

每段提供同步的 **伪彩深度图（Depth_Color）＋红外图（IR）**，最多 **32 帧**，分辨率 **304×228**。深度图保留 RGB 伪彩编码，IR 为 8 位灰度图。训练、验证和测试按人物划分，人物不跨集合。

- **数据包**：`wujie-classification-depth-ir-data.zip`，约 **4.90 GB**。解压后为 `train/` 和 `validation/`，各自包含样本清单与同步图像。
- **开发包**：`wujie-classification-dev.zip`，包含环境安装脚本、微调、验证和分析代码。
- **类别编号**：见两份 `manifest.json` 的 `classes` 数组，索引 **0—39** 对应输出分数的位置；样本的 `label` 使用同一编号。

## 模型微调

### 基线与参数规模

推荐从配套 **R(2+1)D-34 公开预训练微调方案**开始：载入权重，在训练集上微调，在验证集上比较结果，再调整方法。默认使用 **16 帧**，队伍也可选择其他模型或从零训练。队伍的技术说明列明预训练模型、权重来源、许可证、SHA256、训练数据与微调设置。分类器、检测器及其他参与推理的模型，参数总量不超过 **100M**，冻结参数计入总量。

### 数据与预训练范围

队伍可以使用深度图、IR 或两者融合，并调整取帧数量与位置、人物裁剪和输入尺寸。

本届任务训练与推理仅使用提供的 **深度图和 IR**；额外模态不用于本任务的训练、辅助监督、蒸馏或推理。训练集用于参数学习，公开验证集用于方法比较与参数选择。

允许 **通用公开预训练权重**；使用 CUHK 数据训练过的外部权重须说明其训练划分。组织方测试片段及标签不参与训练、伪标签生成或模型选择；公开源数据中本届提供范围以外的 CUHK 片段不作为额外训练数据。

## 开发与验证

开发包提供数据读取、微调、预测、错例报告、同步帧预览和提交检查。

使用 **Linux 或 WSL、Python 3.10**，在开发包目录执行 `bash setup.sh` 安装环境，再按 README 解压数据、下载公开预训练权重并开始微调。

队伍可在本地或租用 GPU 开发，使用公开验证集反复比较方法。各次实验记录准确率、Macro F1、训练设置与运行时间，结合错例和原始帧分析改进方向。

## 提交材料

1. **代码与配置**：推理代码 ZIP、运行配置和依赖说明。训练代码随 ZIP 一并提供，或在技术说明中给出可访问的代码仓库、版本与运行命令。
2. **模型权重**：使用开发包的 `upload_classification_weights.py` 上传，生成 `weights-reference.json`；`prepare_classification_submission.py` 将记录写入推理 ZIP 的 `config.json` 中的 `weights_asset`。网页附件区上传代码 ZIP，权重通过上述脚本单独上传。代码 ZIP 上限 **20 MiB**，单份权重上限 **2 GiB**。
3. **验证结果**：提交 `predict.py` 生成的 `predictions.csv`，列名为 `sample_id,predicted_class`，类别编号为 0—39。
4. **技术报告**：填写在作品 README 中，包含数据处理、模型设计、训练设置、验证结果、实验分析和复现命令，可另附 PDF。表单“推理模型与参数量”填写全部推理模型、参数量合计和统计命令。

### 推理接口

推理 ZIP 根目录包含 `inference.py`、`config.json` 及其依赖文件，在 `inference.py` 定义 `Model`。推理接口为 `Model(config, device).predict(sample_path)`，返回按固定类别顺序排列的 40 个有限分数。`sample_path` 指向当前片段目录，内含同步的 `Depth_Color/` 与 `IR/` 图像。预处理、人物检测和分类过程包含在队伍的推理代码中。

测评程序离线运行；Python、PyTorch 等依赖采用配套环境版本，额外依赖须在开放测评前由组织方登记。人物裁剪使用的 `yolo11n.pt` 已随开发包提供，设置 `detector_file` 后由打包脚本一并放入 ZIP。

## 官网测评

每队有 **3 次**官网自测机会，单次运行上限 **1,800 秒（30 分钟）**，包括领取后的程序包与权重准备、模型初始化和推理，排队不计时。

平台在组织方测试集上运行提交程序，返回准确率、Macro F1、平均推理延迟和项目成果分，并提供各类表现与混淆矩阵。公开验证集可在本地反复运行，不占官网自测次数。

### 正式提交

正式提交时，选择一次已完成的自测，并提交对应版本的代码包、权重和说明。正式提交沿用该次结果，不额外占用自测次数。代码或权重发生变化时，重新自测后选择新结果。
